# Lore Challenge — verification record for the questions added in the 150 → 300 expansion

Scope: the 150 questions numbered 11–20 in each category and difficulty. The original 150 (01–10) are not covered here.

## How to read this record

- **Checked online**: the fact was confirmed in this session against the page listed (secondary source: Tolkien Gateway). The primary work is named only at book/appendix level; no page or chapter numbers are claimed.
- **Not checked online**: written from the published works (The Hobbit, The Lord of the Rings and its Appendices, The Silmarillion) and **not re-confirmed against a source in this session**. These need an editorial pass against the books before the content is treated as verified.
- No passages from the books are reproduced; questions and explanations are in the project's own words.

Known limitation found during checking: the Enerdhil/Elessar attribution was dropped because Tolkien's sources disagree (some name Celebrimbor), so it is not used.
